**Vanguard** превращает Claude Code в штаб. Живая панель показывает отряд субагентов, лимиты и то, чем занято окно контекста. Слой оркестратора учит Claude делить большие задачи между агентами-специалистами, брать свежую документацию и проверять работу, прежде чем сдавать её. Профиль с уровнями и достижениями общий для всех сессий и проектов.

Ставится двумя командами и сам открывается в каждой сессии.

## Установка

В Claude Code:

```text
/plugin marketplace add XXX1694/Vanguard
/plugin install vanguard@vanguard
```

Начни новую сессию или открой панель сразу командой `/vanguard`.

**Требования:** Claude Code 2.1.290 или новее (панель работает на хуках плагинов Claude Code, они в раннем доступе). Для MCP-серверов `sequential-thinking` и `playwright` нужен Node.js 18+.

## Что внутри

### Живая панель

Открывается рядом с диалогом в начале каждой сессии; в любой момент её открывает `/vanguard`.

Панель говорит на **10 языках**: English, Русский, 中文, हिन्दी, Español, Português, 日本語, 한국어, Deutsch и Français. По умолчанию язык берётся из системной локали, а переключатель в конце строки вкладок меняет его сразу. На десктопе это выпадающий список, в терминале — кнопка, которая перебирает языки по кругу. Выбор запоминается в профиле.

Пять вкладок:

| Вкладка | Что показывает |
| --- | --- |
| **Обзор** | Строка цифр: время сессии, субагенты, вызовы, токены агентов, расход. Отряд: главный агент и каждый работающий субагент в виде живого персонажа, который показывает свою роль и чем занят прямо сейчас. Клик по имени открывает страницу агента: задача, последние вызовы инструментов, на какие инструменты он опирался и отчёт, который он вернул. Лимиты со временем сброса и прогнозом, когда кончится 5-часовой, и сжатие с сохранением в один клик. |
| **Контекст** | Из чего состоит окно контекста, как его считает `/context`: системный промпт, инструменты, скиллы, файлы памяти, сообщения, резерв под сжатие. Какие MCP-серверы и CLAUDE.md весят больше всего. |
| **Арсенал** | Твои MCP-серверы, плагины и скиллы. Использованное в сессии подсвечивается со счётчиком. |
| **Достижения** | Уровень и XP, одиннадцать достижений от «Первого вылета» до «Повелителя shell» с прогрессом к следующему и переключатель языка. |
| **Журнал** | Завершённые агенты и события сессии. |

Работает и в терминале, и в десктопном приложении. На десктопе анимированные персонажи, векторные иконки и плавные полосы. В терминале компактная раскладка символами для узкой боковой колонки.

### Оркестратор

Vanguard добавляет в системный промпт короткий набор правил (выключается в настройках):

- сначала оценивать размер задачи: маленькую делать самому, среднюю — с одним-двумя агентами, большую раздавать всему отряду параллельно;
- подбирать модель под агента (Haiku для поиска, Sonnet для механических правок и проверок, модель сессии для проектирования и ревью) и давать каждому точное задание с просьбой о коротком отчёте;
- документацию библиотек брать свежую через Context7, а не по памяти;
- перед сдачей проверять результат: тесты, ревью, для интерфейса — браузер;
- предлагать `/handoff`, когда окно контекста почти заполнено.

**Умная оркестрация.** Правила статичны, поэтому системный промпт остаётся в кэше. Всё живое приходит одной строкой `Vanguard budget:`, которую Vanguard добавляет в диалог только когда меняется тариф или полоса оставшихся лимитов: `plenty` (как обычно), `tight` (больше делать самому, не больше двух агентов, Haiku или Sonnet) или `critical` (нового отряда нет; закончить шаг и предложить `/handoff`). На Pro tight наступает раньше, а окно, которое вот-вот сбросится, считается на полосу ниже. При оплате через API строка показывает стоимость сессии и держит отряд маленьким. Тариф задаётся настройкой `plan` или определяется сам при `auto`.

### Агенты

| Агент | Роль | Модель |
| --- | --- | --- |
| `scout` | Быстрая разведка только на чтение: где что лежит, со ссылками `файл:строка` | Haiku |
| `architect` | Один решительный план, разбитый на параллельные потоки с владением файлами | как у сессии |
| `builder` | Делает один поток работы и прогоняет его проверки | как у сессии |
| `reviewer` | Ищет настоящие дефекты в диффе, по степени серьёзности | как у сессии |
| `verifier` | Запускает тесты, воспроизводит исправления, проверяет веб-интерфейс в браузере | Sonnet |

### Скиллы

| Команда | Что делает |
| --- | --- |
| `/vanguard:orchestrate` | Ведёт отряд на большой задаче: разведка, план, параллельная сборка, ревью и проверка |
| `/vanguard:recon` | Составляет карту незнакомого кода силами параллельных разведчиков |
| `/vanguard:docs` | Достаёт актуальную документацию нужной версии через Context7 |
| `/vanguard:ship-check` | Проверка перед тем, как назвать работу готовой |

### Команды

| Команда | Что делает |
| --- | --- |
| `/vanguard` | Открывает панель |
| `/handoff` | Сжимает контекст с сохранением плана и пишет снимок в `~/.claude/handoffs/`, чтобы продолжить в новой сессии |
| `/limiter` | Переключает ограничитель; `/limiter off` убирает все запросы разрешений, `/limiter on` возвращает их |

### MCP-серверы в комплекте

| Сервер | Зачем | Как запускается |
| --- | --- | --- |
| [Context7](https://context7.com) | Актуальная документация библиотек и фреймворков | Удалённый HTTP, ничего не ставится |
| [Sequential Thinking](https://github.com/modelcontextprotocol/servers/tree/main/src/sequentialthinking) | Пошаговое рассуждение для сложных планов | `npx` |
| [Playwright](https://github.com/microsoft/playwright-mcp) | Настоящий браузер для проверки интерфейсов | `npx` (при первом запуске скачивает браузер) |

### Страж контекста и handoff

Каждое сжатие основного диалога сохраняет цели, решения, состояние работы, работающих агентов, блокеры и следующие шаги. Заодно пишется Markdown-снимок в `~/.claude/handoffs/`. Панель копирует готовый промпт, чтобы продолжить в новой сессии.

### Страж команд

Перед каждым вызовом инструмента, у главного агента и у субагентов, Vanguard проверяет, что сейчас запустится. Он смотрит сквозь `&&`, `;` и пайпы, префиксы `sudo` и `env`, присваивания `VAR=x`, полные пути вроде `/bin/rm` и вложенные `bash -c '...'`.

- **Сначала спрашивает тебя**: `rm -rf` (любое рекурсивное удаление с force), `find -delete` или `-exec rm`, `git push --force` (и `-f`, `--force-with-lease`, `+branch`), `git reset --hard`, `git clean -f`, `git branch -D`, `sudo`, `chmod -R 777`, `curl ... | sh`, `terraform destroy` и `apply -auto-approve`, `kubectl delete`, `npm`/`pnpm`/`yarn publish`, SQL `DROP TABLE`/`DATABASE`/`SCHEMA` и `TRUNCATE`.
- **Спрашивает перед чтением и правкой секретов**: `.env` и `.env.*` (кроме `.env.example`, `.env.sample` и `.env.template`), `*.pem`, `*.key`, `*.p12`, `*.pfx`, приватные SSH-ключи, всё в `~/.ssh`, `~/.aws` и `~/.gnupg`, `.npmrc`, `.netrc`, `.pypirc` и файлы `credentials`. Это касается Read, Edit, Write и `cat`/`head`/`tail`/`cp`/`scp` в терминале.
- **Отказывает сразу**: `rm -rf` на `/`, `/*`, `~` или `$HOME`, `mkfs`, `dd` на дисковое устройство, fork-бомба и `chmod -R 777 /`. Агенту говорится попросить тебя выполнить это самому.

Каждая остановка пишется в Журнал. Чтобы выключить стража, выключи **Страж команд** в настройках.

### Ограничитель

Переключатель вверху панели, на каждой вкладке, или `/limiter` (`/limiter on`, `/limiter off`). **Вкл** (по умолчанию) — Claude Code спрашивает разрешение как обычно. **Выкл** — ничего не спрашивает: любой вызов, на который открылся бы запрос разрешения, у главного агента и у субагентов, выполняется, а Claude получает указание не останавливаться на «продолжать?». Отказы остаются: deny-правила настроек, ограничения организации и список стража «отказывает сразу» по-прежнему останавливают вызов, а собственные вопросы Claude к тебе показываются. Пока ограничитель снят, строка над промптом говорит об этом красным. Выбор запоминается в профиле, пока не включишь обратно.

### Профиль на всё время

Уровни, опыт и достижения хранятся в `~/.claude/vanguard/profile.json`, общем для всех сессий во всех проектах. Опыт начисляется за завершённых агентов, вызовы инструментов, скиллы, вызовы MCP и достижения. Каждое достижение и новый уровень отмечаются баннером и коротким звуком.

## Настройки

Открой `/plugin`, выбери **vanguard**, затем **Configure**:

| Настройка | По умолчанию | |
| --- | --- | --- |
| Язык | auto | `auto` — по системной локали. Переключатель в панели важнее. |
| Правила оркестратора | вкл | Добавлять правила оркестрации в системный промпт |
| Открывать при старте | вкл | Открывать панель в каждой новой сессии |
| Анимации | вкл | Живые персонажи отряда (десктоп) |
| Звук достижений | вкл | Короткий звук при открытии достижения |
| Контекст: предупреждение, % | 70 | Когда страж контекста становится жёлтым |
| Контекст: критично, % | 85 | Когда он краснеет и предлагает handoff |
| Арсенал / Достижения / Журнал | вкл | Показывать эти вкладки |
| Страж команд | вкл | Спрашивать перед опасными командами и секретами, катастрофические отклонять |
| Тариф Claude | auto | `auto`, `pro`, `max`, `team`, `enterprise` или `api`. От тарифа и остатка лимитов зависит, сколько агентов запускает оркестратор. `auto` сам отличает подписку от API. |

## Приватность

У Vanguard нет телеметрии, сам он в сеть не ходит. Пишет только эти файлы:

- `~/.claude/vanguard/profile.json` — твой профиль;
- `~/.claude/handoffs/` — снимки при сжатии.

У MCP-серверов в комплекте свои политики. Context7 получает названия библиотек и темы, о которых ты спрашиваешь. Playwright открывает страницы, которые посещают агенты.

